# Bank logos

SVG assets from https://github.com/omise/banks-logo/tree/master/th (retrieved 2026-11-13).
License retained in LICENSE.txt. Bank trademarks belong to their respective owners.
These are monochrome bank marks displayed on bank-color backgrounds.
Mapping aliases: kkp=kk, lh=lhb, scbt=sc, mizuho=mb.
Banks without a verified bundled asset retain the abbreviation fallback.
`kkp.png`: https://github.com/casperstack/thai-banks-logo/blob/master/icons/KKP.png (current KKP mark instead of legacy Kiatnakin mark).
